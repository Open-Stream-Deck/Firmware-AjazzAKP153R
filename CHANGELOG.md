# Изменения

## [1.0.0] - 2026-11-11

Первый выпуск.

### Устройство

- Прошивка для AJAZZ AKP153R первой ревизии (штатный USB `0300:1020`), дека определяется как `OSD AKP153R`, USB `1209:0001`.
- Ставится через Open Stream Deck поверх штатной прошивки AJAZZ, штатный загрузчик не затрагивается, вернуть прошивку AJAZZ можно тем же способом.
- USB HID в режимах Full Speed и High Speed, полноэкранный поток изображений около 3,8 МБ/с.
- 15 клавиш с подавлением дребезга и одновременными нажатиями.
- При переводе USB в suspend подсветка гаснет, на resume яркость возвращается.

### Дисплей

- Панель 480 x 854, RGB565 через SPI и DMA.
- Протокол OSD1 v1: передача изображений, заливка, линии, окружности, рамки, копирование и смешивание областей видеопамяти, яркость, FENCE для подтверждения кадра.
- Ожидание кадровой синхронизации панели (VSYNC), обновление не разрывается посреди кадра.
- Переход между страницами волной от заданной точки собирается на деке и не занимает канал USB.
- После обрыва потока parser сбрасывается по SYNC и сообщает приложению об ошибке, остаток оборванного изображения не рисуется.
- Диагностика через feature reports: стадии запуска дисплея, заполненность очереди, ошибки протокола, счётчики тактов главного цикла.

### Запуск

- Заставка Open Stream Deck, приложение начинает рисовать сразу, не дожидаясь её окончания.
- Без приложения любая кнопка запускает мини-игру, рекорд хранится до отключения питания.
- Переход в штатный загрузчик командой приложения, без замыкания контактов на плате.
